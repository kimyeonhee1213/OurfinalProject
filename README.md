# Spring 프로젝트 소개
KH 정보교육원에서 수행한 파이널 팀 프로젝트입니다. 

## 프로젝트 주제
주제는 Spring을 활용하여 만든 웹 반려동물 쇼핑몰 및 커뮤니티입니다.

## 개발환경
* 운영체제 :  Window 10
* 개발도구 :  STS, SqlDeveloper
* DBMS : Oracle11gXE
* Server: Apache Tomcat9
* Language : HTML, CSS, JQuery, Ajax, JSP, Java(Servlet), EL/JSTL, JSON, JavaScript, JDK 1.8
* FrameWork : Spring Framework 5.2.22, Bootstrap, Mybatis
* 버전관리 시스템 : git 

## 구현기능
* CRUD기능을 각 모듈별로 모두 구현
* 상품을 장바구니에 담고 실제 결제가 가능하도록 결제API(iamport)를 이용하여 구현
* 일반 로그인을 포함한 OAuth를 사용한 카카오 로그인이 가능하며 회원은 커뮤니티에 글 및 댓글 작성 가능
* 1:1문의 게시판을 통해 문의하고 관리자는 답변을 다는 기능 구현
* 상품에 대한 리뷰는 해당 상품 상세페이지에 작성 가능하도록 구현
